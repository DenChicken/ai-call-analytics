# Документация

Система автоматически оценивает работу менеджеров по записям телефонных
разговоров. Она сама забирает звонки из CRM, расшифровывает их в текст,
оценивает по заданным вами критериям и показывает результат в веб-интерфейсе.

## С чего начать

Если система еще не установлена, читайте документы по порядку:

1. [Как устроена система](overview.md) - что происходит со звонком от CRM до
   отчета. Прочитайте до установки, дальше будет понятнее.
2. [Установка](installation.md) - подготовка сервера и первый запуск.
3. [Секреты](secrets.md) - пароли и ключи доступа, которые нужно подготовить.
4. [Критерии оценки](criteria.md) - главная настройка: за что система ставит
   баллы менеджерам.

## Повседневная работа

- [Веб-интерфейс](webui.md) - что показывают экраны и как ими пользоваться.
- [Эксплуатация](operations.md) - запуск и остановка, пользователи, журналы,
  резервные копии, место на диске, обновление версии.
- [Настройки](configuration.md) - полный справочник всех параметров.
- [Производительность](performance.md) - как ускорить обработку и что выбрать:
  видеокарту или обычный процессор.
- [Решение проблем](troubleshooting.md) - что делать, если что-то не работает.

## Коротко о главном

- Система работает на вашем сервере. Записи разговоров и результаты никуда не
  передаются, интернет нужен только один раз - чтобы скачать модели.
- Настройка выполняется через текстовые файлы с расширением `.toml`. Программы
  менять не нужно.
- Все команды выполняются из папки, в которую распакован поставленный архив.
- Работа системы ограничена сроком действия лицензии.
